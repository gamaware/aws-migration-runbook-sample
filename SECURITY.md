# Security policy

## What this repository contains

Everything here describes **Harbor Goods, a fictional retailer**. The inventory, IP addresses, hostnames and account
IDs are synthetic or come from documentation ranges (`203.0.113.0/24`, `example.com`, `123456789012`). The Terraform
has never been applied to a real account from this repository.

## Reporting a vulnerability

Report problems in the Terraform, the check scripts or the CI workflows privately through
[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)
on this repository. Please do not open a public issue.

Include the file, the command you ran and what you expected. You will get an acknowledgement within five working
days. Contribution, conduct and support guidelines are inherited from the
[gamaware/.github](https://github.com/gamaware/.github) repository.

## Supported versions

Only the `main` branch is maintained.
